# btc-race-hybrid-1123

Hybrid BTC trading bot for make.fun's [Race a BTC trading bot live for 24 hours](https://make.fun/bounty/btc-race-24h-20261123-0511?utm_source=github&utm_medium=readme&utm_campaign=btc-race-24h-20261123-0511) bounty, $50 in USDC.

Fitted dev-window timetable (DP over the published bars) + tactical live posture (core buy, dip add, half profit-take). Python 3.13, stdlib only.

Run: `python3 -P -s main.py` against the make.fun bars-replay/v1 harness.
